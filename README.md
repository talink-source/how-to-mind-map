# How to Mind Map

A Claude skill that turns your expertise into an interactive mind map. Start with an outcome you own, such as “How to drive growth for a company.” The skill keeps asking “how?” until each branch ends in a task someone can put on a calendar, with a clear output.

Use it to document how you work, make your judgment visible to a team, or decide which tasks to hand off or teach AI to do first.

## Get started

1. [Download the installable ZIP](https://github.com/talink-source/how-to-mind-map/raw/refs/heads/main/how-to-mind-map.zip).
2. Follow the [installation guide](INSTALL.md) for Claude or Claude Code.
3. Tell Claude what outcome you want to map and share any notes, playbooks, or examples you already use. You can also fill in the [intake template](assets/intake-template.md).

Try this prompt after installing:

> Use the how-to-mind-map skill to map how I onboard a new client. Start with my attached notes and flag the gaps for me to review.

## What you get

- An editable outline that serves as the source for the map.
- An interactive HTML mind map with competence ratings on a 1–4 scale.
- A Markdown copy for reading and sharing.

See the [growth strategy example outline](references/example-outline.txt) for a sample, or read [SKILL.md](SKILL.md) for the full workflow.
